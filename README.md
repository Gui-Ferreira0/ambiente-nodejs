# ambiente-nodejs
# Preparação do Ambiente Node.js com TypeScript

## 📖 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de configurar um ambiente de desenvolvimento back-end utilizando **Node.js** e **TypeScript**, realizando a inicialização do projeto, configuração dos arquivos essenciais e execução da aplicação por meio de scripts do **npm**.

Como teste de funcionamento do ambiente, foi criada uma aplicação simples que exibe mensagens no terminal utilizando `console.log()`.

## 🎯 Objetivos

* Configurar um ambiente de desenvolvimento com Node.js e TypeScript.
* Inicializar um projeto utilizando o npm.
* Configurar os arquivos `package.json`, `tsconfig.json` e `.gitignore`.
* Executar aplicações TypeScript utilizando o comando `npm run dev`.
* Versionar o projeto utilizando Git e GitHub.
